- Servidor Doméstico (Media, Cloud & Gaming)
Este servidor funciona sobre Debian Linux y utiliza Docker. Está dividido en múltiples entornos independientes para separar la automatización de descargas audiovisuales del drive local.

1. Stack Multimedia y Descargas
Ecosistema automatizado para buscar, descargar mediante VPN y reproducir contenido.

Servicios: Jellyfin (reproductor), Sonarr/Radarr (gestores), Prowlarr (buscadores), qBittorrent (descargas), FlareSolverr (proxy), Gluetun (VPN) y FlareSolverr (evade los bloqueos de Cloudflare).

2. Drive Personal (Nextcloud)
Nextcloud es una plataforma que te permite crear tu propia nube privada. Funciona exactamente igual que Google Drive, iCloud o Dropbox, pero alojada físicamente en tu propia máquina.


3. Servidor de minecraft
Servidor dedicado de Minecraft para mundos persistentes.
